Entry for [Laugh Track: The Crypto Trading Joke Contest](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a) — a single joke about crypto and trading life, capped at 200 characters, plain text.

## The joke

> Bought the dip. The dip dipped. Now I own a museum of red candles and a PhD in holding bags.

(92 characters, one line.)

## Why it works

Every trader knows the "buy the dip" mantra — and every trader has watched the dip
keep dipping after they bought it. The joke lands in three beats: the confident
buy, the betrayal, and the punchline, where the loss is reframed as an accidental
collection (a museum of red candles) and a fake credential (a PhD in holding bags).
It is funny because it is true: in trading life, the diploma you actually earn
is the bag you refuse to sell.

## How it works

`main.py` (Python 3.13, standard library only, no network calls) writes the joke
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), asserting first
that it is a single line of 1–200 characters. Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/test-out-crypto-joke python3 main.py
```
